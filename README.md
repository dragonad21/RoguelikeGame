# RoguelikeGame
Implementation Roguelike game in Java 21 with Lanterna UI

## 📖 Описание

**RoguelikeGame** — это пошаговая рогалик-игра с процедурной генерацией подземелий, боевой системой, системой инвентаря и сохранением прогресса. Игра реализована на Java 21 с использованием библиотеки Lanterna для терминального интерфейса.

Игрок управляет персонажем, исследует подземелья, сражается с монстрами, собирает предметы и пытается пройти все 21 уровень.

---

## 🎮 Геймплей

| Механика | Описание |
|----------|----------|
| **Пошаговое движение** | Игрок перемещается по карте, враги ходят после каждого хода |
| **Генерация уровней** | Каждый уровень генерируется процедурно: комнаты, коридоры, выход |
| **Боевая система** | Шанс попадания зависит от ловкости; урон — от силы и оружия |
| **Инвентарь** | 9 слотов для предметов: оружие, еда, эликсиры, свитки |
| **Экипировка оружия** | Оружие даёт бонус к силе; можно экипировать/снять |
| **Туман войны** | Видимость ограничена радиусом; можно включить/отключить (`v`) |
| **Сохранение** | Автоматическое сохранение при переходе между уровнями |

## 🧭 Управление

| Клавиша | Действие |
|---------|----------|
| `w/a/s/d` | Движение |
| `i` | Открыть инвентарь |
| `h` | Оружие |
| `j` | Еда |
| `k` | Эликсиры |
| `e` | Свитки |
| `1-9` | Использовать предмет |
| `>` | Переход на следующий уровень (стоя на выходе) |
| `v` | Вкл/выкл туман войны |
| `ESC` | Выход в главное меню |

## 🧟 Враги

| Враг | Особенность |
|------|-------------|
| **Зомби** | Базовый враг |
| **Вампир** | Первый удар не наносит урона |
| **Призрак** | Может быть невидимым |
| **Огр** | Высокое здоровье и урон |
| **Змее-маг** | Атакует магией, усыпляет игрока |
| **Мимик** | Маскируется под предмет; раскрывается при попытке подобрать |

---

## 📦 Предметы

| Тип | Действие |
|-----|----------|
| **Оружие** | Экипируется, даёт бонус к силе |
| **Еда** | Восстанавливает здоровье |
| **Эликсиры** | Увеличивают характеристики (сила, ловкость, здоровье) |
| **Свитки** | Одноразовое усиление характеристик |
| **Сокровища** | Превращаются в золото, не занимают место в инвентаре |

## 🏗 Архитектура

Проект построен по **MVC** (Model-View-Controller) и разделён на слои:
core/
├── controller/ ← Управление потоком (GameController)
├── domain/ ← Бизнес-логика (Game, Player, Enemy, Item, etc.)
├── datalayer/ ← Сохранение и загрузка (DTO + сериализация)

presentation/
└── view/ ← Отображение (GameView, MainMenuView, PackView, etc.)
└── renderers/ ← Рендереры для карты, врагов, предметов
